PopSpell brand assets supplied by the site owner. Use the wordmark and illustrations without cropping their content.

## Pip, the PopSpell mascot

Five poses from the owner's Pip pack, each trimmed to its outline, centred on a transparent square, and saved at 480px (`pip-<pose>.webp`) and 160px (`pip-<pose>-small.webp`). The mascot and celebrate poses also have a 240px PNG for emails, because some email apps can't show WebP.

| Pose | Used for |
|---|---|
| `mascot` | Home page welcome, branded emails |
| `hop` | The child's current stop on Pip's sound journey |
| `listen` | Start screens of lists and activities |
| `think` | Starting checks, My sounds, My stories |
| `celebrate` | Results screens, My bests, the parent page |

To add a pose, save it as `pip-<name>.png` with a transparent background, make the two WebP sizes the same way, and use `pipHTML(size, mood, says, "<name>")` in `app.js`.
